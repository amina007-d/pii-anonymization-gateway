\section{Introduction}

\subsection{Purpose}

This document specifies the functional and non-functional requirements for the PII Anonymization Gateway, a system that detects personal data in text before it is sent to external artificial intelligence (AI) services, replaces the data with reversible pseudonyms and restores the original values in the response. The requirements are the basis for the design, the user interface prototype, the implementation and the evaluation of the system.

\subsection{Sources of Requirements}

The requirements were derived from the following sources:
\begin{itemize}
\item the project proposal, which defines the aim, objectives and scope of the project;
\item the Law of the Republic of Kazakhstan ``On Personal Data and Their Protection''~\cite{law}, which regulates the processing and cross-border transfer of personal data;
\item the literature review, in particular the prompt sanitization prototypes Casper~\cite{casper} and PromptShield~\cite{promptshield} and the Kazakh named entity recognition dataset KazNERD~\cite{kaznerd};
\item the comparison of existing systems, including the experiment with Microsoft Presidio~\cite{presidio}, which showed that individual identification numbers (IIN) were not recognized without customization;
\item the user survey ($n=35$) described in the document \emph{Evidence of Relevance};
\item the technology comparison, where the first versions of FR-1--FR-5 and NFR-1--NFR-3 were used as decision criteria.
\end{itemize}

The identifiers FR-1--FR-5 and NFR-1--NFR-3 keep the meaning they have in the technology comparison; this document details them and adds the remaining requirements.

\section{System Overview}

The system consists of four components deployed within the organization's infrastructure:
\begin{enumerate}
\item \emph{Anonymization service} (server): detects personal data, creates pseudonyms, stores the mapping and restores responses; it exposes a REST interface.
\item \emph{Browser extension}: intercepts text in the web interfaces of ChatGPT and Gemini, shows the detected data, sends the anonymized text and restores the response on the page.
\item \emph{API proxy}: provides an interface compatible with the programming interfaces of OpenAI and Gemini for service accounts.
\item \emph{Administration panel}: web interface for policies, users, security settings, the log and statistics.
\end{enumerate}

Only anonymized text leaves the organization. Original values and the mapping remain on the organization's server.

\section{Functional Requirements}

Priorities follow the MoSCoW method: \emph{Must} requirements form the minimum viable product for the first release; \emph{Should} requirements are planned for the final version; \emph{Could} requirements are implemented if time allows. Each requirement has an acceptance criterion that is verified in the evaluation (see the document \emph{Evaluation Plan}).

Missed personal data cannot be recalled once sent, whereas a false alarm only costs the user one click; however, frequent false alarms lead users to confirm without reading. Detection quality is therefore evaluated primarily by recall and by the F2 score, which weights recall twice as much as precision, under a minimum precision constraint. This also follows the user survey, in which 51\% of respondents preferred detecting all personal data even with occasional false alarms.

FR-3.3 & The mapping shall be stored on the server for the duration defined in NFR-2 and shall be available only to the request that created it & Must & Mapping is not accessible with another session token \\ \midrule

FR-4.1 & Pseudonyms in the AI response shall be replaced with the original values & Must & At least 95\% of test responses fully restored \\ \rl

FR-4.3 & Restoration shall tolerate inflected pseudonyms (for example, a suffix added by the model) & Should & At least 90\% of inflected pseudonyms restored \\ \rl

FR-5.4 & The user shall be able to preview the text that the AI service will receive & Should & Preview available before sending \\ \rl

FR-5.6 & The user shall sign in with an organization account; the extension shall work only with the organization's server & Must & Requests without a valid token are rejected \\ \rl
FR-5.7 & The extension interface shall be available in Kazakh, Russian and English & Should & All screens translated \\ \midrule

FR-7.4 & The administrator shall manage users and assign the roles in Table~\ref{tab:roles} & Must & Role restrictions enforced by the server \\ \rl
FR-7.5 & The administrator shall configure the mapping retention period, the behaviour on failure and the NER confidence threshold & Should & Settings applied to new requests \\ \midrule
\multicolumn{4}{l}{\textbf{FR-8. API proxy}} \\*
FR-8.1 & The system shall provide an endpoint that anonymizes text and returns the anonymized text and detections & Must & Endpoint documented in OpenAPI \\ \rl
FR-8.2 & The system shall provide a proxy compatible with the OpenAI and Gemini chat interfaces, including streaming, which anonymizes the request and restores the response & Should & An unmodified OpenAI client library works through the proxy \\ \rl
FR-8.3 & Provider keys shall be stored on the server and never sent to clients & Must & No provider key in client traffic \\

\section{Constraints and Assumptions}

\begin{itemize}
\item Only text is processed; images, PDF files, audio and video are out of scope.
\item The browser extension is developed for Chromium-based browsers (Manifest V3).
\item Changes in the web interfaces of ChatGPT and Gemini may require updates of the extension adapters; the API proxy is the stable alternative.
\item Detection quality is evaluated only on a synthetic corpus with fictitious identifiers in a valid format; real personal data are not used.
\item The NER model must run on a CPU server without a graphics processor.
\item Detection cannot be complete: the review step (FR-5.2, FR-5.3) and the policies (FR-6) reduce the risk of missed data but do not eliminate it. Quasi-identifiers and attribute inference~\cite{lukas} are not addressed by this system.
\end{itemize}
