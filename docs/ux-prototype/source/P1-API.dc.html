API прокси: программный доступ

Для внутренних систем организации (CRM, чат-боты), которые обращаются к LLM напрямую. Все запросы — HTTPS + JSON с токеном JWT или ключом сервисного аккаунта. Документация генерируется автоматически (OpenAPI / Swagger). Все данные в примерах вымышленные.

POST/v1/anonymize— найти и заменить персональные данные (FR-1, FR-2, FR-3)
Запрос
{
  "text": "Клиенту Иванову Сергею Петровичу (ИИН 850315300009) позвонить по +7 (705) 111-22-33",
  "language": "auto",
  "policy": "default"
}
Ответ 200
{
  "request_id": "req_7f3a91",
  "anonymized_text": "Клиенту <PERSON_1> (ИИН <IIN_1>) позвонить по <PHONE_1>",
  "entities": [
    { "type": "PERSON", "token": "<PERSON_1>", "start": 8, "end": 32, "score": 0.97 },
    { "type": "IIN", "token": "<IIN_1>", "start": 38, "end": 50, "checksum_valid": true },
    { "type": "PHONE", "token": "<PHONE_1>", "start": 63, "end": 81 }
  ],
  "languages": ["ru"],
  "expires_in": 900,
  "processing_ms": 142
}
Исходные значения в ответе не возвращаются: словарь замен хранится на сервере, зашифрован и удаляется через expires_in секунд.
POST/v1/chat/completions— прокси, совместимый с форматом OpenAI: обезличить → отправить → восстановить (FR-4, FR-8)
Запрос
Authorization: Bearer <JWT>

{
  "provider": "openai",
  "model": "gpt-4o",
  "stream": true,
  "messages": [
    { "role": "user",
      "content": "Составь письмо Иванову Сергею Петровичу, ИИН 850315300009" }
  ]
}
Потоковый ответ (SSE), значения уже восстановлены
data: {"id": "req_8c21d0", "choices": [ {"delta": {"content": "Уважаемый "} } ]}

data: {"id": "req_8c21d0", "choices": [ {"delta": {"content": "Иванов Сергей Петрович"} } ]}

data: {"id": "req_8c21d0", "choices": [ {"delta": {"content": "! Ваш ИИН 850315300009 ..."} } ]}

data: {"id": "req_8c21d0", "pii": {"replaced": 2, "restored": 2} }

data: [DONE]
Псевдоним, разорванный между фрагментами потока, буферизуется до полного получения и только потом восстанавливается.
POST/v1/restore— восстановить значения в тексте, полученном от LLM другим путём
Запрос
{
  "request_id": "req_7f3a91",
  "text": "Уважаемый <PERSON_1>, перезвоните по номеру <PHONE_1>."
}
Ответ 200
{
  "text": "Уважаемый Иванов Сергей Петрович, перезвоните по номеру +7 (705) 111-22-33.",
  "restored": 2,
  "unknown_tokens": []
}
403Блокировка политикой— текст с номером карты при политике «Блокировать» (FR-6)
{
  "error": "blocked_by_policy",
  "entity_types": ["CARD"],
  "message": "Text contains data types blocked by organization policy"
}
